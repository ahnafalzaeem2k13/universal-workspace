# SKYBOUND — The Last Signal

A third-person 3D adventure built with Three.js.

Run `npm install`, then `npm run dev`.

Desktop: WASD/arrows move, Space jump, Shift dash, E restore beacon, P/Escape pause. Mobile: virtual joystick, Jump and Dash buttons.

Collect eight signal shards, restore three beacons, and reach the Sky Gate. Avoid sentry drones; shards restore shield.
