# Agent Skills installation

This folder is populated by tools/refresh_agent_skills.py.

- The library is versioned in this GitHub repository, so it survives Colab runtime resets.
- INDEX.md lists the installed skills and source commits.
- sources.lock.json records upstream repository URLs and exact commit SHAs.
- Root AGENTS.md tells compatible coding agents to select and read skills automatically.
- To refresh manually: python tools/refresh_agent_skills.py.
